# Home Automation

A smart home automation project built in Unity.

## Project Structure

```text
HOME/
├── Assets/
│   ├── Scripts/      # C# control scripts
│   ├── Scenes/       # Unity scenes 
│   └── ...
├── Packages/
├── ProjectSettings/
└── README.md

```

## Requirements

* **Unity Version:** 2022.3.12f1 or later

## Setup & Run

1. Clone or download this repository.
2. Open **Unity Hub**.
3. Click **Add project from disk** and select the project folder.
4. Open the project and load the main scene.
